# 🛒 E-Commerce Sales Dashboard

An interactive Power BI dashboard developed to analyze e-commerce sales performance across different states, categories, customers, payment methods, and time periods. The dashboard provides valuable business insights through dynamic visualizations, KPIs, and interactive filters, enabling effective data-driven decision-making.

---

## Tech Stack

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel / CSV Dataset

---

## Data Source

- E-Commerce Sales Dataset (CSV)
- Contains information such as:
  - Order ID
  - Order Date
  - Customer Name
  - State
  - Category & Sub-Category
  - Sales Amount
  - Quantity
  - Profit
  - Payment Mode

---

## Features

- Interactive dashboard with Quarter and State filters
- KPI Cards displaying Total Sales, Profit, Quantity, and Average Order Value (AOV)
- Monthly Profit Analysis
- State-wise Sales Analysis
- Category-wise Quantity Distribution
- Customer-wise Sales Analysis
- Payment Mode Distribution
- Profit Analysis by Product Sub-Category
- Interactive cross-filtering across visuals

---

## Dashboard Highlights

- Maharashtra recorded the highest sales amount.
- Clothing contributed the largest share of total quantity sold.
- Cash on Delivery (COD) was the most preferred payment method.
- November generated the highest monthly profit.
- Printers were the most profitable product sub-category.
- Interactive filters allow users to explore business performance across different dimensions.
